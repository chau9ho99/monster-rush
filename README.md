# 怪獸突襲 · Monster Rush

四關單人街機射擊遊戲。揀一位主角，守住防線，擊倒每關嘅 Boss。

[公開試玩](https://chau9ho99.github.io/monster-rush/)

第三關「風暴天橋」要對付瓷面爬鬼同裂顎喪犬，穿過電網缺口，再避開空殼喪鐘嘅攻擊，趁核心外露反擊。

[第四關「沙漠風暴」](https://chau9ho99.github.io/monster-rush/?stage=4) 有青金聖甲蟲同赤砂獵豺。沙塵暴會不定時來襲，警報響起約 1.5 秒後濃霧會遮住遠處敵人。留意風向，逆風走位；曜核蠍皇出雙鉗嗰陣，走入青色沙道再反擊。

頭三關嘅小怪會停低鎖定，再射出單發、三叉或交叉火力。可以趁蓄力打斷，或者沿虛線之間嘅空位閃避。主角必殺冷卻 11 秒，可以清怪同消除敵彈；對護甲中嘅 Boss 最多扣 5% 滿血，核心外露時上限升到 20%。

## 點玩

- 手機用左邊搖桿移動，拖右邊搖桿瞄準同開火。
- 電腦用 WASD 或方向鍵移動，用滑鼠左鍵或 IJKL 射擊。
- 長按「儲氣」或空白鍵，滿格放手出必殺。按朋友頭像或 F 召喚隊友，第二關每局兩次，其餘關卡各一次。
- 執金幣後按「升級」或 U 強化武器。標題畫面可以撳「開聲試聽」。
- LV2 起會不定時有道具跌落戰場，走近落地嘅道具就會拾取。補能藥水加 50% 必殺儲氣，滿儲氣藥水即刻充滿，之後撳一下必殺掣或空白鍵就可以出招。
- 特殊武器道具會隨機出稜光散射炮、電離貫穿炮或日焰連發炮。拾取後使用 8 秒，時間到自動切返原本武器。

遊戲使用 HTML、CSS、Canvas 同 Web Audio。開啟靜態網頁伺服器就可以本機試玩。
